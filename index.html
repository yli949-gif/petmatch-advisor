Problem

People often make adoption decisions emotionally, but the long-term outcome depends on whether their daily lifestyle can support the pet they want. This project flags high-risk mismatches before that decision becomes expensive or irreversible.

Features

  • Hours away: how much daily time the adopter is not at home
  • Activity level: low, medium, or high lifestyle intensity
  • Housing type: apartment or house
  • Pet type: dog or cat
  • Pet energy level: how much stimulation and exercise the pet needs

Model Logic

The system uses interpretable rule-based classification logic instead of a black-box model. That choice is deliberate: for decision support, clear reasoning matters more than squeezing out marginal accuracy that users cannot understand or trust.

Data And Validation

The current dataset is synthetic, built from realistic pet-care constraints and domain logic. Validation is scenario-based: simulate adoption cases, score mismatch risk, then test whether changing user behavior reduces that risk.

Analytical Insight

The strongest predictors of mismatch are time availability and pet energy level. High-energy pets paired with long hours away or low-activity adopters create the clearest high-risk patterns.

Project impact: reduce high-risk decisions by translating risk signals into clear, behavior-based guidance instead of just reporting information.

Model Rules

The Python model scores each case using interpretable additive rules. It does not try to hide logic behind coefficients or embeddings. The risk label is then derived from the final score threshold.

Rule 1: Time Away

If hours away are very high, risk increases because supervision, attention, and routine care become harder.

Rule 2: Energy Mismatch

High-energy pets paired with low-activity adopters sharply increase risk. This is the strongest driver.

Rule 3: Housing Constraint

A high-energy dog in an apartment adds risk because exercise and stimulation are harder to sustain.

Rule 4: Dog Care Load

Dogs generally require more structured daily interaction, so long time away raises risk further.

Rule 5: Supportive Activity

High-activity adopters can slightly offset risk for low-energy pets because they can maintain stable routines.

Label Rule

After scoring, cases are classified as high risk or low risk. The design prioritizes catching high-risk cases.

if hours_away >= 8: +3 if pet_energy == "high" and activity == "low": +4 if housing == "apartment" and pet_type == "dog" and pet_energy == "high": +3 if pet_type == "dog" and hours_away >= 6: +2 if activity == "high" and pet_energy == "low": -1 risk = "high" if score >= 5 else "low"
