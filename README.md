# PetMatch Advisor

A data-driven behavioral decision system designed to reduce high-risk pet adoption mismatches.

## Problem
Many adoption failures happen because people underestimate their lifestyle constraints.

## Solution
This system guides users through a decision process:
- Select desired pet
- Input lifestyle factors
- Detect mismatches
- Simulate future consequences

## Key Features
- Mismatch risk scoring
- Behavior-guided decision flow
- Future outcome simulation

## Tech
- HTML / CSS / JavaScript
- Rule-based risk model

## Impact
Helps users reflect on decisions and reduces high-risk adoption scenarios.
